-> Container: A simple wrapper to apply consistent styles (width, padding) to its children.

-> Footer: A styled footer containing links to various sections of the website, along with copyright information.

-> Header: A navigation header that includes the logo and dynamic links based on user authentication status. It also includes a logout button.

-> LogOutBtn: A button component that triggers a logout action when clicked, updating the Redux state accordingly.

-> PostForm: A form for creating or updating blog posts. It handles file uploads, slug creation, and integrates with the Appwrite service for data submission.

-> Input: A generic input component that can handle different types of input fields.

-> RTE: A controlled rich text editor component for inputting content in a formatted manner.

-> Select: A dropdown select component for choosing from predefined options.

-> Button: A customizable button component for various actions throughout the application.
